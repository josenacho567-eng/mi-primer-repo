# Agenda de contactos
Proyecto de práctica de Git.
## Cómo usar

Este proyecto es una agenda personal sencilla manejada mediante archivos de texto. A continuación se explica para qué sirve cada archivo del repositorio:

* **README.md**: Es la presentación del proyecto y contiene la documentación y las instrucciones de uso.
* **contactos.txt**: Almacena tu directorio personal. Cada línea contiene el nombre de un contacto, seguido de su número de teléfono y su correo electrónico.
* **tareas.txt**: Sirve para llevar un registro de tus actividades pendientes o cosas por hacer.
* **compras.txt**: Es una lista donde puedes anotar los artículos o alimentos que necesitas adquirir en el supermercado.
* **.gitignore**: Es un archivo de configuración interno de Git. Se encarga de ocultar archivos que no deben guardarse ni publicarse, como contraseñas (`secretos.txt`) o archivos temporales.
